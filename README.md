# Alter Mkt — sitio web

Landing page de Alter Mkt (marketing digital & IA para PYMES).

Un solo archivo autocontenido (`index.html`): HTML + CSS + JS, sin dependencias de build. Se puede hostear directo en Netlify, Vercel, GitHub Pages o cualquier hosting estático.

## Cómo verlo local
Abrí `index.html` en el navegador, o corré un server simple:

```
npx serve .
```

## Contenido a personalizar
- Logo real (hoy es un logotipo de texto en `ALTER`/`MKT`)
- Portafolio con casos reales (hoy usa Camytex Studio, Alter Haus y Fluvial)
- Datos de contacto (WhatsApp, email, Instagram) ya están cargados con los reales de Alter Mkt
